# Contributing

Thank you for reading, and for wanting to help.

This is a personal blog, and every commit in it is authored by the repository owner. The `commit-policy`
check enforces that, so pull requests from other accounts can't be merged, however good they are.

The best ways to contribute:

- **Corrections and questions:** open an [issue](https://github.com/anandnarayanan2017/anandnarayanan-blog/issues).
  Typos, broken links, technical mistakes and unclear explanations are all welcome. If you include a
  suggested fix in the issue, I'll apply it myself and credit you in the commit message.
- **Discussion:** comment on the article's post on [LinkedIn](https://linkedin.com/in/anandkn2012).
- **Security issues:** don't open a public issue. Report them privately as described in
  [SECURITY.md](SECURITY.md).
