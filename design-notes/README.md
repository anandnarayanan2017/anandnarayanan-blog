# Design notes

Standalone architecture pieces that do not belong to a series. Each note describes a system that exists and
links to the code, tests or records behind its claims, like the series do.

The notes are listed on the site's [Architecture](https://anandnarayanan.net/architecture/) page, next to the
design-heavy parts of the series. `docs/blog/series.json` gives this folder no home-page card, so a note appears
under "Design notes" there and in "Latest writing" on the home page, but not under "Start here".
